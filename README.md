|---------|-----------|-----------|
| [ProjetoOsceola](./ProjetoOsceola) | Sistema de verificação de vida de um personagem | Variáveis, `if/else if`, Console I/O |

## 🛠️ Tecnologias

- **Linguagem:** C#
- **Plataforma:** .NET 10

## 🚀 Como executar

1. Certifique-se de ter o [.NET SDK](https://dotnet.microsoft.com/download) instalado
2. Clone o repositório:
   ```bash
   git clone https://github.com/SEU_USUARIO/EstudosCSharp.git
   ```
3. Navegue até o projeto desejado e execute:
   ```bash
   cd EstudosCSharp/ProjetoOsceola
   dotnet run
   ```
